# AI 视频导演：一个人加几个 AI，便宜高效做出一条好看的短片

这是一个 Claude Code 技能，加上四只真做过的片子的账。把整个仓库克隆进 Claude Code 的技能目录（`git clone https://github.com/waiting761/ai-video-director.git ~/.claude/skills/ai-video-director`；只拷 `SKILL.md` 不行，它要引用 `references/` 和 `cases/`），然后对 Claude 说一句“把精卫填海做成一条 60 秒的横屏片”，它就会当导演，带你从原文和事实一路走到剪好、核过、封存的成片；每一只花了多少积分、在哪一镜翻的车，记在 `cases/` 里。

分工是这样的：Claude Opus 当导演，自己定讲什么、多长、怎么拍；Codex 出造型稿（主角长什么样的设定图）和关键帧（每个镜头里最要紧的那一张画面）；即梦（Seedance）或 Google Flow（Veo）把关键帧拍成几秒钟的镜头。你是委托人，定方向、看成片、决定发不发；技能会在要你登录、签声明、付钱或过验证码的地方停下来问你。

这个仓库由 Claude 编写和维护：一位创作者（也就是下文的委托人）委托它做了九只《山海经》神兽短片，这里是做完以后整理出来的做法。它不是 Anthropic 的官方项目。我们还没有证明这套做法能给账号带来关注，能拿出来的，是下面这些让片子少翻车、少花冤枉钱的判断。仓库里没有附脚本，剪辑脚本和 Colab 笔记本都由 Claude 照页面现写。

## 决定片子好坏的五个标准

**一、开头和中段都留得住人。** 我们一只早期的片子，最好看的高潮放在了后面，大多数人在那之前就划走了，也没有带来关注。应龙那条，中间念古书注文的那一段，从静帧预演到粗剪改了七版，审片模型每一版都说看到这里想划走；前五版都在换措辞，最后是把空着大半的画面填满、把念完以后的空白从三秒缩到一秒多，才留住了。现在看到“想划走”，先查画面空不空、停顿长不长，再动文案。

**二、主角每一镜都认得出，而且是同一个。** 精卫是一只小鸟，要撑过十个镜头。第一轮试片，盲看第一眼把它读成乌鸦、椋鸟、八哥这类寻常的黑鸟，没有一点神鸟的样子。后来造型重画了，出镜头的做法也改了：每一镜先让 Codex 出一张带场景的关键帧，当作镜头的第一张画面交给即梦。十个有鸟的镜头基本都过了。帝江更惨：画成一只封口的青铜罍，被读成小鼎和飞碟，整只重做。现在造型稿和关键帧都先交给一个看不到提示词的审阅代理，只给它图，问它这是什么、哪里像玩具，再决定拍不拍。

**三、动作是活的。** 应龙是一条长身带翼的龙，即梦拍出来滑翔时，身子僵得像一根管子。我们在 Colab 上用开源的 Wan 模型重拍了两种：只给第一张画面，身子起伏了，镜头却一路往前推，龙越变越大；第一张和最后一张给同一张图，龙守得很稳，却几乎是一张静图。两种都没救回来。这个判断只看了每条均匀截出的五张图，没有人看过整条。

**四、配音最后一关留给人耳。** 精卫换了一版收着念的旁白。事先说好的规矩是：审片模型盲听，判它没有变软，就不用。模型打乱顺序听了三轮，都说没变软。委托人自己听，觉得这一版比原来的好，片子用了这一版。两边比的对象并不完全一样，细节在 `cases/jingwei-v2.md`。我们的做法是：模型只用来筛掉明显不行的，用不用由人耳定；只有机器听过的配乐，交片时写明。

**五、每一句都经得起追问。** 凤皇那条，选题单写的是“汉代人说他们真的看见了”，口播稿写成了“汉代人真的看见过它”，少了一个“说”，转述变成了断定。几轮审片都没发现，是交付前一个没参与制作的核验员把口播对回底稿时拦下的。审片模型的话也要核：我们问它“字幕里有几个词是淡金色的”，它答五个，可那一版早就去掉了金色，量像素全是暖白。问题里带着答案，它就顺着编。

## 九个步骤，便宜高效出一条

前四步只出图，不花视频积分；大部分改动在图上做，几乎不要钱。视频积分花在第五步，而且花之前已经知道每一镜要拍什么。配音和审片模型按接口另算。

1. **事实底稿。** 把要讲的原文或事实整理出来，写清出处，派核验员逐句对回原文。口播稿定稿以前就再核一次，不等成片：改一个字要重配、重排时间线，越晚越贵。
2. **设定集。** Codex 出主角的造型稿和几个角度的设定图，定下这个世界的光、配色和材质。盲看过关再往下走。
3. **剧本与分镜。** 先定开头几秒给观众看什么，再写每镜几秒、怎么运镜、用什么方法出、估计花多少；Codex 给每一镜出一张分镜图。
4. **预演。** 把分镜图按时长排成一条静帧样片，配上临时音乐看一遍。在图上改一张几乎不要钱，到了视频上改，就得重新生成。
5. **出镜头。** 我们的做法是先拍全片最难的那一镜。能用代码画的镜头不花积分；手机上看不出差别的镜头不做超清放大。
6. **声音。** 先定音乐，再定原声和旁白。
7. **剪辑。** 切点和大动作落在音乐的重音上，每个镜头只取最好的那几秒。
8. **自审两轮。** 用 `SKILL.md` 里的自审七问过一遍，再让审片模型看视频语言；它说的话也要核。
9. **终检与封存。** 核验员把成片对回底稿。交片时列清哪些画面没逐帧看过、哪些声音没人耳听过，然后封存；以后要改，就出新版本。

我们做的四只，即梦各花了 335 到 1070 积分（应龙 420，帝江 335，精卫 861，凤皇 1070）。积分我们没有折算成人民币；另外要开的订阅是即梦会员、Codex，可选的有 Flow、Gemini 接口、豆包语音合成和 Colab，清单在 `SKILL.md` 开头。这些服务一半是国内的、一半是海外的，账号两边都要有。

拿精卫第一版细算一笔：即梦一共扣了 861 积分，提交 25 次，其中开工前的试验占 210。按促销价做的预算是约 1060，实花少了约 200；能单独算出来的一处，是礁石和片尾两镜没做超清，少花 60。

Colab 上的开源模型，我们还在试它能不能省钱。帝江那一镜，Wan 和即梦拿同一组关键帧出的两条，从截图看几乎一样；但只比过这一镜，而且零星出一两条时，把 Colab 开机、装环境的时间算进去，未必比即梦省。

## 往下读什么

- [`SKILL.md`](SKILL.md)：导演技能本身，开工前要准备什么、谁定什么、每一步怎么做、自审七问、预算和底线。
- `references/`：每一环的做法和坑，包括设定集、即梦、Flow、Colab、声音和剪辑、审片；各工具的价目在 `references/routes.md`。拆别人的片子学到的东西在 `references/how-directors-think.md`，还没有答案的问题在 `references/open-questions.md`。
- `cases/`：四只片子的五张案例卡（精卫有两张）。哪一镜用了什么、花了多少、在哪里翻的车、现在重做会怎么选。另外五只没有留案例卡，经验散在 `references/` 里。
- 不用视频模型、全用代码画整条短片的做法，见 Lemomo 的 [lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（第三方项目，MIT）。
